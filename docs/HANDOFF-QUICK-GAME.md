# ✅ ВЫПОЛНЕНО: режим «Быстрая игра» (12.08.2026)

Хендофф отработан полностью, промт ниже больше не нужен.

## Что построено

- **Вкладка «Быстрая игра»** в шапке после «Создать игру» → `/quick`;
  пункт «Игры» на мобильном скрыт (логотип ведёт на ленту).
- **`/quick`** — клиентский режим матч-дня без бэкенда, состояние в
  localStorage (`avento_quick_day_v1`), гидратация через
  useSyncExternalStore (`src/modules/quick/presentation/quick-day-store.ts`).
  Поток: кто пришёл (имя + «Гость») → составы 2–3 команд (нажатие
  переводит игрока дальше, карандаш — имя и цвет из 6 пресетов) →
  выбор первой пары → матч (таймер старт/пауза, тап по счёту = гол,
  «Кто забил?» с автором и ассистентом, отмена гола) → подтверждение
  результата с ротацией (победитель остаётся; при ничьей уходит тот,
  кто дольше на поле — правило написано в UI) → таблица дня
  (3/1/0, очки → разница → забитые) → журнал с правкой счёта
  плюс-минусом → публикация: текст итогов (share/clipboard) и
  карточка-PNG 1080×1350 на canvas.
- **`/quick/demo`** — тур на 10 шагов: статичные мини-моки экранов под
  вуалью `bg-background/70`, яркая карточка шага, «Далее»/«Пропустить»,
  прогресс «3 / 10», reduced-motion учтён; «Начать игровой день» не
  затирает уже идущий день.
- **Домен с тестами**: `src/modules/quick/domain/standings.ts` и
  `rotation.ts`, тесты `tests/unit/quick-standings.test.ts` и
  `quick-rotation.test.ts` (18 кейсов).
- Цвета команд — CSS-переменные `--quick-team-*` в `globals.css`
  (в светлой теме затемнены до читаемости на бумаге).
